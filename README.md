# Breast Cancer ML Classification Pipeline

## Overview

Machine learning pipeline for breast cancer classification using clinical features.

## Objective

To classify malignant and benign breast tumors while evaluating performance using clinically relevant metrics such as sensitivity, specificity, ROC-AUC and false negative analysis.

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- Sensitivity
- Specificity
- F1 Score
- ROC-AUC

## Dataset

Breast Cancer Wisconsin Dataset from Scikit-learn.

## Future Work

- Deep learning based medical imaging models
- Multimodal healthcare AI
- Larger cancer datasets

## Pipeline

The project follows an end-to-end ML pipeline:

1. Data loading
2. Data preprocessing
3. Feature scaling
4. Model training
5. Model evaluation
6. Clinical performance analysis
